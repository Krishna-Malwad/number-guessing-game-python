# 🎯 Number Guessing Game (Python)

An interactive Number Guessing Game built using Python.

This project includes:
- Multiple difficulty levels
- Score system
- High score tracking
- Input validation
- Hint system
- File handling

---

## 🚀 Features

### ✅ Difficulty Levels
- Easy → 1 to 50
- Medium → 1 to 100
- Hard → 1 to 200

### ✅ Score System
Players earn scores based on:
- difficulty level
- remaining attempts

### ✅ High Score Tracking
High scores are stored using file handling in:
```txt
high_scores.txt
```

### ✅ Input Validation
Handles:
- invalid inputs
- non-numeric values
- out-of-range numbers

### ✅ Hint System
Provides hints like:
- Go Higher
- Go Lower
- Very Close
