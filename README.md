# 🎯 Number Guessing Game (Python)

A simple Python-based number guessing game with difficulty levels, attempt limits, scoring system, and replay option.

---

## 🚀 Features

- 3 Difficulty Levels:
  - Easy (1-50)
  - Medium (1-100)
  - Hard (1-200)

- Limited attempts based on difficulty
- Score system based on performance
- High score tracking using file handling
- Replay option after each game

---

## 🧠 How to Play

1. Run the program
2. Choose difficulty level
3. Guess the number
4. Follow hints (higher/lower)
5. Try to win before attempts end

---

## 🛠 Tech Used

- Python
- Random module
- File handling
- Loops and conditions
